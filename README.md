# whichstackfits

Marketing site for [WhichStackFits](https://whichstackfits.com) — comparisons of CRM, email & automation, scheduling, and all-in-one platforms for 1–20 person service businesses.

Next.js App Router + TypeScript + Tailwind CSS. Deploys on Vercel.

## Develop

```
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```
